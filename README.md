# 치이카와 안내자 (치이카와 입문 RAG 챗봇)

"치이카와가 뭐야?"라고 묻는 입문자에게 **에피소드 요약 자료를 근거로** 답해 주는 RAG 챗봇입니다.
유튜브 공식 전편공개 에피소드(1~248화 중 공개된 246편)를 Gemini로 요약해 벡터 DB에 넣고,
질문이 들어오면 하이브리드 검색으로 근거를 찾아 OpenAI 모델이 답합니다.

## 빠른 실행

Python 3.12 기준입니다.

```bash
pip install -r requirements.txt
```

이 폴더에 `.env` 파일을 만들고 키를 넣어 주세요. (키 파일은 공유하지 않았습니다)

```
OPENAI_API_KEY=sk-...
OPENAI_DEFAULT_MODEL=<답변·판정에 쓸 OpenAI 채팅 모델 이름>
EMBEDED_MODEL=text-embedding-3-small
TAVILY_API_KEY=tvly-...

# 노트북에서 요약을 다시 만들 때만 필요
GEMINI_API_KEY=...
```

- `EMBEDED_MODEL`은 철자가 D 하나입니다(코드와 맞춤). `chroma4`가 이 모델(1536차원)로 만들어져 있어서 바꾸면 안 됩니다.

```bash
streamlit run app.py
```

## 파일 구성

| 파일                    | 설명                                                                                                             |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `app.py`              | Streamlit 챗봇 앱 (검색·판정·답변·화면 전부)                                                                  |
| `requirements.txt`    | 앱 실행용 패키지                                                                                                 |
| `episodes.csv`        | 에피소드 목록 (`episode_id`=화수, `video_id`, `title`, `video_url`)                                      |
| `raw_json/`           | 에피소드별 Gemini 요약 (`characters`, `summary`, `key_scenes`, `objects`)                                |
| `chroma4/`            | 앱이 쓰는 벡터 DB (청크 1,304건)                                                                                 |
| `치이카와_새db.ipynb` | `raw_json` → `chroma4` 적재, 하이브리드 검색 실험                                                           |
| `치이카와_짝꿍.ipynb` | Gemini 요약 파이프라인 (`episodes.csv` → `raw_json`). 뒷부분의 검색 코드는 초기 버전이라 현재 앱과 다릅니다 |

노트북을 실행하려면 `pip install google-genai pandas`도 필요합니다.

## 동작 방식

```
질문
 → 하이브리드 검색: BM25(kiwipiepy 형태소 + 불용어 + 캐릭터 별칭 변환) + 벡터 검색을 RRF로 합침
 → 에피소드 단위로 묶기 (상위 5편, 편당 청크 최대 2개)
 → 1차 필터: BM25 키워드가 맞았거나 벡터 유사도 ≥ 0.3
 → 2차 판정 (LLM)
     · 치이카와와 무관한 질문      → "제가 가진 자료에는 없어요" 고정 답변
     · answerable (자료로 답 가능) → DB 근거로 답변 + 유튜브 영상 링크
     · correctable (이름·전제 착각) → 착각을 먼저 바로잡고 DB로 답변
     · unanswerable (관련이지만 자료 없음) → 웹 검색(Tavily) + "웹에서 찾아봤어요" 안내 문구
 → 답변 끝에 추천 질문 버튼 2개
```

- **청크**: 에피소드마다 줄거리 1 + 장면 N + 등장 사물 1. 모든 청크 앞에 `[N화 제목 | 등장 캐릭터]` 접두어가 붙어 있습니다.
- **별칭**: 토끼→우사기, 고양이→하치와레, 다람쥐·하늘다람쥐·날다람쥐→모몽가, 해달→랏코, 밤만쥬→쿠리만주
- 사이드바에서 1차 필터 임계값, 검색 에피소드 수(k), 검색 과정 보기를 조절할 수 있습니다.

## 주의할 점

- **경로에 한글이 있으면 chromadb(1.5.x)가 DB를 못 읽습니다.** `app.py`는 시작할 때 자기 폴더로 이동해서 상대 경로 `chroma4`를 쓰도록 처리돼 있습니다. 노트북도 이 폴더에서 실행해 주세요.
- 에피소드 119화, 240화는 비공개라 빠져 있습니다.

## 알려진 한계

- **캐릭터 소개·줄거리 개요 질문은 대부분 웹으로 답합니다.** DB에 장면 조각만 있고 캐릭터별 정리 문서가 없기 때문입니다. 평가 질문 15개 중 DB로 답한 것은 5개였습니다.
- **요약 품질 검수 전입니다.** 예: 5화 라면 이름이 '까르메라우'로 적혀 있음(실제로는 '챠루메라'로 추정). 요약에 "친구들", "다른 캐릭터"처럼 이름이 빠진 표현이 많습니다.
- 웹 답변의 정확성은 보장되지 않습니다. 그래서 웹 답변에는 안내 문구와 출처 링크를 항상 붙입니다.
